# متابعة إصلاح K1

هذه متابعة للمراجعة التاريخية [`e84c96e`](kernel-security-e84c96e.md)، التي تصف حالة ذلك الـcommit ولا تُعاد كتابتها لتبدو وكأن الإصلاح كان موجودًا آنذاك.

## ما تغير

الـcommit `c2d83f5185fe190ce376dde155a04a805fecb626` غيّر التحقق لالتقاط الخصائص من أوصاف بيانات مملوكة بدل استدعاء getters، ورفض accessors والحقول الإضافية والمخفية والرمزية، وتحويل أخطاء الاستبطان إلى رفض للخطة. تُختبر الخطة كاملة قبل الموافقة والتنفيذ.

يقبل التنفيذ كائنات JS بشكل بيانات JSON، وليس بديلًا عن تحليل JSON عند حد النقل الموثوق. لا يمكن اكتشاف جميع أنواع Proxy شفاف في JavaScript، وقد تُنفذ مصائد Proxy أثناء الاستبطان؛ النواة ليست sandbox لكود غير موثوق.
