# عقود المكونات المقترحة

هذه عقود تصميمية وليست واجهات برمجية منفذة. يُراجع إصدارها قبل التنفيذ، وتضاف اختبارات توافق لكل محول عند بنائه.

## قواعد مشتركة

- كل عملية تحمل معرّف طلب، ونوع العملية، ونطاق البيانات، وحالة واضحة: نجاح، رفض، حاجة لموافقة، غير متاح، أو فشل. لا تُسجل الأسرار أو محتويات المستخدم افتراضيًا.
- وصف كل محول يشمل معرفًا وإصدارًا، والقدرات، والوجهة محلية أم خارجية، والصلاحيات المطلوبة، وسياسة التكلفة والحالة. «مجاني» ليس ضمانًا دون تحقق من إعدادات المزود وحدوده.
- لا يُعاد تنفيذ عملية ذات أثر جانبي تلقائيًا ما لم تكن قابلة للتكرار بأمان أو تحمل مفتاح منع التكرار؛ وإلا يُطلب تدخل المستخدم عند غموض النتيجة.
- تعرض الأخطاء سببًا مفهومًا وإمكانية إعادة المحاولة دون كشف المفاتيح. المهلات وحدود إعادة المحاولة تمنع التكرار اللانهائي.

## العقل ومزودو الذكاء

**الطلب:** المهمة، البيانات والسياق المسموح بإرسالهما، القدرات المطلوبة، سياسة الخصوصية والتكلفة، وحدود التنفيذ.
**النتيجة:** المخرجات، معرف المحول، الحالة، وأي استخدام أو تكلفة متاحة من المزود مع بيان أنها قد تكون تقديرية.
**الفشل والبديل:** لا يُختار بديل إلا إذا كان مفعلًا ومتوافقًا مع الصلاحيات والموافقة وسياسة التكلفة والبيانات. لا تُرسل البيانات إلى خدمة جديدة اعتمادًا على موافقة لخدمة أخرى. إذا لم يوجد بديل مؤهل يُعرض الفشل دون ادعاء النجاح.

## الذاكرة والبيانات المحمولة

**العمليات:** إنشاء وقراءة وتعديل وحذف، وتصدير واستعادة. تتضمن السجلات معرفًا ثابتًا ونوعًا وإصدار مخطط وتواريخ مناسبة، مع تحديد مصدر الحقيقة محليًا.
**التصدير:** حزمة قابلة للنقل بإصدار تنسيق وبيان محتويات والبيانات والملفات التابعة لها؛ تستبعد بيانات الاعتماد والسجلات الحساسة افتراضيًا. يُحذر المستخدم أن التصدير غير المشفر قد يكشف بياناته.
**الاستعادة:** التحقق من إصدار التنسيق وسلامة المحتويات قبل التعديل، ومعالجة المسارات غير الآمنة، وعرض التعارضات، وعدم الكتابة فوق البيانات بصمت. يجب أن يكون الفشل قابلًا للتعافي دون ترك حالة جزئية صامتة.
**الإثبات:** اختبار حفظ البيانات بعد إعادة التشغيل، وتصديرها ثم استعادتها، والتعامل مع ملف تالف أو إصدار غير مدعوم. لا يُعد تصميم التصدير تطبيقًا أو ضمانًا للنسخ الاحتياطي.

## الأدوات والاتصالات

**وصف الأداة:** الاسم، الوظيفة، المدخلات، نوع الأثر، الصلاحيات، الوجهة الخارجية إن وجدت، وحالة الاتصال.
**التنفيذ:** تمر الطلبات عبر الحوكمة قبل المحول؛ تتطلب الكتابة أو الحذف أو النشر أو الإرسال الخارجي موافقة صريحة مسبقة تحدد العملية والوجهة ونطاق البيانات. صلاحيات القراءة أيضًا محدودة بما تتطلبه المهمة.
**النتيجة:** نجاح أو خطأ مع أثر معروف أو حالة غير مؤكدة؛ عدم اليقين لا يُعرض كنجاح. لا يشير وجود محول مقترح إلى اتصال فعلي بالخدمة.

## الموافقات والأسرار

- الموافقة مرتبطة بالعملية والوجهة ونطاق البيانات والتكلفة المحتملة، ويمكن رفضها أو إلغاؤها قبل التنفيذ. لا تكفي موافقة سابقة غير ذات صلة.
- تُحفظ بيانات الاعتماد في مخزن أسرار مناسب للجهاز عند التنفيذ، لا في الشيفرة أو Git أو سجل الأحداث أو حزمة التصدير العادية. لم يُختر مخزن أو يُختبر بعد.
- استخدام صلاحيات محددة وقابلة للإلغاء، وعدم منح وصول شامل افتراضيًا. تظهر العمليات الحساسة في سجل محلي محدود التفاصيل دون كشف الأسرار.

## الاستمرارية

يفحص النظام حالة المحول وحدوده عندما يكون ذلك ممكنًا دون تكلفة أو تسريب غير مطلوب. يميّز بين انقطاع الشبكة، ونفاد الحصة، وانتهاء الصلاحية، والرفض، والفشل غير المعروف. بعد الفشل يختار بديلًا معتمدًا ومؤهلًا فقط؛ إن لم يوجد يعرض السبب والخطوة الممكنة. لا يضمن وجود بديل مجاني أو محلي لكل مهمة.
