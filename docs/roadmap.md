# خريطة الطريق ومعايير الإثبات

الحالة: **المرحلة 0 والوثائق الأولية للمرحلة 1 قيد المراجعة**. المراحل التالية مخططة وليست منفذة. لترتيب تنفيذ المشروع القائم، الذي يبدأ بالتشخيص وإصلاح البناء، انظر [خطة التنفيذ الحالية](existing-project-plan.md)؛ أرقام الجدول أدناه تصف مجالات العمل لا ترتيب التنفيذ الملزم.

| المرحلة | النتيجة المخططة | دليل الإكمال المطلوب |
|---|---|---|
| 0 — الهوية | اعتماد العالم المرئي ومركز القيادة، وأولوية المجانية | توثيق القرارات والقيود وحدود المشروعات |
| 1 — الأساس | تثبيت المعمارية والعقود واختيار الترخيص والتقنيات | مراجعة العقود والتراخيص، وتعليمات تشغيل واختبارات قابلة للتكرار عند بدء التنفيذ |
| 2 — العقل | واجهة موحدة ومحولات نماذج اختيارية | اختبار طلب ناجح، وعدم توفر نموذج، وبديل مؤهل أو رسالة عدم وجوده، دون رسوم غير مصرح بها |
| 3 — الذاكرة | تخزين دائم محلي وتصدير واستعادة | إعادة تشغيل، واستعادة نسخة، واختبار تلف وتعارضات دون فقد صامت |
| 4 — الأدوات | محولات مختارة لخدمات مثل GitHub وDrive بعد التحقق | اختبارات اتصال فعلية بإذن المستخدم، وموافقات، ورفض أو انتهاء صلاحية؛ توثيق ما لم يُختبر |
| 5 — الاستقلال | بدائل حسب الموارد والقدرات المتاحة | اختبار فشل مزود وتحويل آمن إن وُجد بديل مؤهل، أو عرض عدم توفره |
| 6 — الواجهة | لوحة عربية وإنجليزية ومساحة مرئية تدريجية | تشغيل فعلي، واختبارات الاستخدام والاتجاه RTL وإظهار الموافقات والحالات |
| 7 — الإثبات | تقرير ميزات وحدود واختبارات | نتائج قابلة للتكرار للنجاح والحفظ والفشل والبديل حيث ينطبق، مع إعلان النواقص |

## قاعدة قبول مشتركة

لا تكفي كتابة الشيفرة وحدها. لكل ميزة: اختبار نجاح فعلي، وإثبات بقاء البيانات عبر إعادة التشغيل عندما تخزن بيانات، واختبار فشل، واختبار بديل مسموح إن كان متاحًا أو توضيح غيابه. التكامل الخارجي لا يُعلن عمله قبل اختباره فعليًا، ولا تُنفذ عملية مدفوعة أو حساسة دون موافقة. الاختبارات التي تحتاج حسابات أو موارد غير متاحة تُذكر باعتبارها غير منفذة، لا ناجحة.
